# Font pairings

Load from Google Fonts in index.html (one link tag, both families, weights 400/500/600/700),
then set `--font-sans` and, when a display font is used, `--font-display` in index.css and
apply `font-display` to headings.

| pairing | heading | body | feel |
|---|---|---|---|
| modern | Inter Tight | Inter | neutral, tech |
| grotesk | Space Grotesk | Inter | confident, sneakers, street |
| editorial | Fraunces | Inter | warm, bakery, craft |
| serif-luxe | Playfair Display | Source Sans 3 | salon, beauty, luxury |
| rounded | Manrope | Manrope | friendly, community, schools |
| geometric | Outfit | Outfit | events, startups |
| classic | Libre Baskerville | Lato | law, consulting, real estate |
| bold | Sora | Inter | fitness, bold offers |

Rule: never more than two families. Headings semibold, body regular. Tracking tight on
headings above text-3xl only.
